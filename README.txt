COGNIQI - MOCKUP ESTÁTICO

Como abrir:
1. Extraia o ZIP.
2. Abra index.html no navegador.
3. Clique em "Começar avaliação".
4. Responda as 10 questões demonstrativas.
5. O resultado é salvo em localStorage e usado nas páginas seguintes.

Arquivos principais:
- index.html: landing page
- teste.html: avaliação interativa
- resultado.html: resultado gratuito + bloqueio comercial
- checkout.html: checkout simulado
- relatorio.html: relatório completo demonstrativo
- dashboard.html: área do usuário
- assets/css/app.css: identidade visual e responsividade
- assets/js/app.js: dados compartilhados/localStorage
- assets/js/teste.js: lógica da avaliação mock
- assets/img/logo-cogniqi.svg: logomarca vetorial

Observações:
- O Bootstrap está carregado por CDN, então o layout fica melhor com internet.
- Não existe backend, pagamento real, autenticação ou banco de dados.
- O score é apenas uma simulação de UX e NÃO representa cálculo psicométrico válido.
